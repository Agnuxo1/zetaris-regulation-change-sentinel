# Scientific research and release policy

Project: Zetaris — Regulation Change Sentinel  
Original research author: Francisco Angulo de Lafuente  
ORCID: https://orcid.org/0009-0001-1634-7063  
Policy date: 2026-11-03  
Existing repository license: MIT (do not silently alter).

All new **original** source code should include unobtrusive, accurate SPDX copyright, identifier, project, date and ORCID metadata as legal comments/docstrings. Keep user-facing and machine-readable attribution in README, CITATION.cff, AUTHORS.md, codemeta.json, and provenance/identity.jsonld.

Require complete reproducible code, pinned dependencies, documented seeds/splits, raw numerical evidence, independent audit, professionally written English documentation, a genuinely animated scientific README header GIF and an informative SVG flow diagram. Mark conceptual figures explicitly and never fabricate experimental results. Check all assets and README links.

Do not publish secrets, private datasets, hidden evaluation labels, restricted model weights, or other people's copyright material without authorization. Do not overwrite third-party license headers. Keep MIT notices and all applicable upstream notices. For MIT-licensed original work, the binding condition is retention of the original copyright and permission notice in copies or substantial portions; asking for a scholarly citation is not an additional MIT license obligation.

Never label a task COMPLETE until the full publishable repository has been validated, pushed, and independently verified by remote commit SHA. A submitted contest entry requires separate organizer proof; GitHub is not proof of official submission.
